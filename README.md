# 🏥 AI-Powered Healthcare Prediction & Resource Management System

An intelligent healthcare web application built using **Python, Streamlit, Machine Learning, and SQLite**.  
This system helps in **early disease prediction, patient management, and doctor-patient interaction** using AI.

Live link :- https://necmajor3-ai-health-care-system.onrender.com

---

## 🚀 Features

### 👤 Patient Module
- Secure login & registration system
- AI-based disease prediction:
  - Diabetes Prediction
  - Heart Disease Prediction
  - Kidney Disease Prediction
- View medical history
- Download medical reports as **PDF**
- Book doctor appointments
- Chatbot for basic health queries
- Upload lab reports

---

### 👨‍⚕️ Doctor Module
- Secure doctor login
- View patient details and history
- Provide prescriptions & treatment plans
- Monitor patient health records
- View analytics and reports
- Emergency patient alerts (if enabled)

---

## 🤖 Machine Learning Features
- Trained ML models for disease prediction
- Risk analysis based on patient input data
- Smart health recommendations
- Data-driven decision support system

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit  
- **Backend:** Python  
- **Machine Learning:** Scikit-learn, Pandas, NumPy  
- **Database:** SQLite  
- **Other Tools:** Joblib, Pickle, ReportLab (PDF generation)
